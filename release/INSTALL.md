# Installation der Bildedition

Die Bildedition wird atomar als Release-Paket eingespielt. Die bisherige Startdatei bleibt bis zum vollständigen Upload unverändert. PINs und Spielcodes werden nicht im Paket gespeichert, sondern nur aus den Render-Umgebungsvariablen gelesen. Der Installationsprozess prüft die Prüfsumme und führt vor dem Start Tests aus.
